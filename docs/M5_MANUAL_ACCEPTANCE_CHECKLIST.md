# M5 手机与三网人工验收清单

更新日期：2026-11-13（Asia/Shanghai）

## 当前是否可以使用

中国大陆正式链路已经具备受控试用条件：

`www.resilience-training.cloud` → EdgeOne Pages → `api.resilience-training.cloud` → 腾讯云 Fastify/PostgreSQL。

自动化已通过登录、AI、完成保存、刷新后回放、42/42 模块入口、代表性深层交互、普通事件断网重试、刷新恢复、跨标签页和并发启动。正式招募约 100 名参与者前，仍需完成下面的手机实机和移动网络检查。

## 需要人工完成的最短清单

使用测试身份 `C_TEST / sxq`，不要使用正式参与者编号。每次测试记录手机型号、系统版本、浏览器和网络。

### 1. 一台真实手机完整业务路径（必须）

- [ ] 使用手机浏览器打开 `https://www.resilience-training.cloud`，确认 HTTPS 正常、没有证书警告。
- [ ] 登录后进入模块 1-1，完成一次输入和 AI 回复，确认回复能够显示。
- [ ] 完成模块并刷新页面，确认显示只读回放，不会重新生成另一份内容。
- [ ] 切到后台约 30 秒后返回，确认页面没有黑屏、崩溃或丢失登录状态。

### 2. 音频与视频实机播放（必须）

- [ ] 打开模块 1-5，确认 MP3 可以开始播放、暂停和继续，手机不会因播放而出现黑屏或页面冻结。
- [ ] 打开模块 5-2，确认气球示范 MP4 能显示画面、播放、暂停和拖动；如果浏览器选择 MOV 备用源，也应能播放。
- [ ] 音视频播放时切到后台再返回，确认页面仍可操作；系统主动暂停媒体属于正常行为，但返回后应能手动继续。
- [ ] 分别在 Wi-Fi 和至少一种手机流量下播放一次，确认没有长时间卡在加载状态。

### 3. 中国移动、联通、电信业务路径（正式招募前建议完成）

每种网络至少完成：

- [ ] 打开首页并登录。
- [ ] 触发一次 AI 回复。
- [ ] 完成一个短模块并刷新确认回放。
- [ ] 播放一段音频或视频。

可以使用三台不同运营商手机，也可以让三名测试人员分别完成。此前三网首页访问已通过，本项重点检查登录后的 API、AI 和媒体链路。

## 通过标准

- 页面和 API 无证书、跨域或持续加载错误。
- AI 请求能够成功；偶发网络切换后重新操作可以恢复。
- 完成状态刷新后仍存在，不重复生成 run。
- 音视频能开始播放且页面不黑屏、不冻结。
- 如果某项失败，记录：时间、手机型号、系统、浏览器、网络运营商、模块编号、操作步骤和截图；不要发送参与者真实姓名、API key、数据库密码或其他密钥。

## 回报格式

可以直接回复：

```text
手机型号 / 系统：
浏览器：
网络（Wi-Fi/移动/联通/电信）：
1-1 登录、AI、完成、刷新回放：通过/失败
1-5 音频：通过/失败
5-2 视频：通过/失败
后台 30 秒返回：通过/失败
异常现象与截图：
```

若一台手机的必测项全部通过，可先开始小范围内部试用；正式面向约 100 人开放前，再补齐三网登录后业务路径。
